## ⚡ Part 7: Technical SEO Audit & Production Implementation

### 7.1 Static Prerendering (Search Engine Crawler Readiness)
- Every single route (`/`, `/about`, `/products/*`, `/gallery`, `/contact`) is statically prerendered at build time via `scripts/prerender.js`.
- Search engine spiders (Googlebot, Bingbot) receive 100% crawlable, fully rendered HTML without executing JavaScript.

### 7.2 Core Web Vitals Targets
- **Largest Contentful Paint (LCP):** `< 1.2s` (Hero background and product images served in optimized `.webp` format with `eager` loading on LCP targets).
- **Cumulative Layout Shift (CLS):** `0.00` (All images and iframe embeds have explicit `width`, `height`, and `aspect-[...]` ratios).
- **First Input Delay / Interaction to Next Paint (INP):** `< 50ms` (Clean lightweight React footprint without bulky UI libraries).

### 7.3 Robots.txt Configuration
Make sure `public/robots.txt` contains:
```txt
User-agent: *
Allow: /

Sitemap: https://globaloffsetpatna.com/sitemap.xml
```

### 7.4 Canonical URLs & Open Graph
- Every page is configured with a dynamic canonical tag via `SeoHelmet.jsx` to prevent duplicate parameter indexing.
- Complete Open Graph (`og:title`, `og:description`, `og:image`, `og:url`, `og:type`) and Twitter Cards (`summary_large_image`) on all routes.
